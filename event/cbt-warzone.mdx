Tunjukkan skill terbaik, hadapi lawan di medan perang, dan raih kemenangan. Aturan umum ada di halaman [Warzone Event](/fitur/warzone-event).

## Jadwal

| Info | Detail |
| --- | --- |
| Hari | Akan diumumkan |
| Tanggal | Akan diumumkan |
| Waktu | Akan diumumkan (WIB) |

## Hadiah

| Kategori | Hadiah |
| --- | --- |
| Pemenang | 25.000 CC |
| Partisipan | 10.000 CC |

Seluruh peserta juga berkesempatan mendapatkan hadiah partisipasi sesuai ketentuan event.

## Pendaftaran

Pendaftaran dilakukan melalui Discord resmi Luna Tenkai. Peserta wajib mengirim **full screenshot** karakter yang menampilkan:

1. Karakter secara utuh.
2. Tab Status.
3. Tab Inventory.
4. Tulis IGN + JOB.

Pastikan seluruh bagian screenshot terlihat jelas dan tidak terpotong agar data karakter dapat diverifikasi.
